# Gincana_Hacker

Propus desenvolver uma gincana tecnológica na minha faculdade. A ideia foi criar uma competição chamada "Cyber Escape", que consiste em um minigame com várias salas. Em cada sala, os participantes precisam descobrir uma senha para desbloquear o próximo nível.

O objetivo é simples: escapar da sala, encontrando as senhas escondidas em enigmas e desafios presentes em cada fase. Cada enigma resolvido revela a senha necessária para avançar para o próximo nível.
